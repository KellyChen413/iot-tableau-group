## 稽核意見

以原始 CSV 重新計算後，**76 項數值與資料完整性檢查全部通過，未發現本次指定數值的分母錯用**。此結果適用於本報告記錄的資料版本與計算定義。

## 6. 異常關聯性交叉稽核

### 6.1 馬達：過熱與 error 重疊程度低

| 馬達（共 20,500 筆） | error | 非 error | 合計 |
|---|---:|---:|---:|
| 溫度 >80°C | 63 | 345 | 408 |
| 溫度 ≤80°C | 322 | 19,770 | 20,092 |
| 合計 | 385 | 20,115 | 20,500 |

溫度無缺值，因此表中未達門檻可直接表示為 ≤80°C。

- error 中過熱比例（涵蓋率）：63／385＝**16.36%**。
- 過熱中 error 比例（精確率）：63／408＝**15.44%**。
- 交集占聯集（Jaccard）：63／(385＋408−63)＝**8.63%**。
- 過熱狀態分布：normal 185、warning 154、error 63、offline 6。

**稽核判定：不能支持「馬達 error 與過熱高度重疊」。** 監測 >80°C 可用來觀察熱風險，但不能以其代替既有 error 狀態；408 與 385 兩個總數接近，並不代表是相同紀錄。本資料亦不足以判定溫度與狀態不同步的原因。

### 6.2 壓力計：高震動精確率高，error 涵蓋率有限

| 壓力計（共 30,750 筆） | error | 非 error | 合計 |
|---|---:|---:|---:|
| 震動 ≥15 | 128 | 2 | 130 |
| 震動 <15 | 279 | 30,341 | 30,620 |
| 合計 | 407 | 30,343 | 30,750 |

壓力計震動無缺值。

- 高震動中 error 比例（精確率）：128／130＝**98.46%**。
- error 中高震動比例（涵蓋率）：128／407＝**31.45%**。
- error 中震動 <15 的比例：279／407＝**68.55%**；這 279 筆溫度全部 >55°C。
- 「震動 ≥15 或溫度 >55°C」涵蓋 407／407＝100% 的壓力計 error。這僅是 error 端的涵蓋率，不能解讀為此聯集條件的精確率也是 100%。

**稽核判定：數據支持高震動作為重要監測訊號，但不支持它涵蓋全部 error。** 「低中震動仍有 error」與「高震動中多為 error」不矛盾，兩者使用不同分母。描述性關聯也不能證明因果或保證未來資料維持相同比例。

## 7. 比對差異常見原因與判讀限制

| 原因 | 本次處理與核對重點 |
|---|---|
| 四捨五入 | 使用原值運算，最終依圖表位數採 Decimal `ROUND_HALF_UP`；Python `round()` 的半偶數規則可能在臨界值不同。 |
| 浮點數 | 尾端可能有極小誤差；整數筆數仍須完全相等，不應以浮點容差掩蓋筆數差異。 |
| NULL／NaN | `AVG`／`mean()` 排除缺值；`COUNT(column)` 不等於 `COUNT(*)`。腳本先揭露缺值，比例依題意使用全部列數。 |
| 分母範圍 | 全體狀態率用 92,250；設備類型比率用該類型全部列；門檻中的 error 用達門檻列數；error 涵蓋率用全部 error。 |
| 聚合順序 | 每筆直接平均與先算每日／各設備平均再平均，可能產生不同權重；本次依全部紀錄直接聚合。 |
| 時間定義 | 使用 timestamp 原始時間，不轉換時區；使用 created_at 或改時區可能改變小時與日期結果。 |
| 門檻邊界 | >80 不含 80；>100 不含 100；≥15 含 15；<15 不含 15；>55 不含 55。 |
| Tableau 資料範圍 | 篩選、資料來源版本、extract 更新時間、聯結倍增、LOD／表計算範圍均可能影響結果，須另核對工作簿設定。 |
| 去重與補值 | 本次不刪列、不去重、不補值；僅驗證 log_id 唯一性，未將跨 log_id 的相似紀錄判為重複。 |
| 類型與空白字元 | 未自動修剪或改寫 status／device_type；未知類別會使集合檢查失敗，避免靜默合併。 |
| 適用範圍 | 本次是 29 天資料的描述性重現，不等於感測器校正、工安門檻認證或未來故障預測驗證。 |
